# herdr-daytona-sandbox

Planned Herdr plugin for running Claude Code, Codex, OpenCode, and Pi in persistent Daytona sandboxes, with reviewed patches returned to a local Git worktree.

The repository currently contains the [implementation plan](docs/plans/2026-11-16-1306-feat-daytona-sandbox-plugin-plan.md). Implementation has not started; the auto-stop default remains a user decision.
