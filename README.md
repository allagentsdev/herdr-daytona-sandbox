# herdr-daytona-sandbox

Planned Herdr plugin for running Claude Code, Codex, OpenCode, and Pi in persistent Daytona sandboxes, with reviewed patches returned to a local Git worktree.

The repository currently contains the [implementation plan](docs/plans/2026-11-16-1306-feat-daytona-sandbox-plugin-plan.md), following existing Herdr sandbox plugin conventions. Implementation has not started. The approved default stops sandboxes after 15 minutes of inactivity while retaining their files.
